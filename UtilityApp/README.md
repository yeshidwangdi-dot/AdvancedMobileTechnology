# Utility App — Currency Converter

Android assessment project based on the lecturer-provided MobileTech_UtilityApp starter template.

Features: AUD, USD, EUR, GBP and BTN conversion using **illustrative fixed rates**, currency swap, clear, input validation, ViewModel state, and Compose Material 3 UI.

**Not live exchange rates. Do not use for financial decisions.**

## Android Studio
Open the complete project from the downloadable submission ZIP, sync Gradle (compile SDK 36), and run the app on an Android 8+ device or emulator.
